# ผลเทียบข้อมูลเว็บไซต์ CSTUHub กับ Sources

ตรวจเมื่อ: 9 ตุลาคม 2026 (เวลาไทย)

## ขอบเขตและหลักฐานที่ตรวจ

- เว็บไซต์จริง: [CSTUHub](https://main.d2q46seuxuluap.amplifyapp.com/)
- เปิดทั้ง Collaborator และ Event & Activities โดยไม่ได้ใส่คำค้นหาหรือตัวกรอง พบ **13 คู่ความร่วมมือ และ 13 กิจกรรม**
- ตอนตรวจเว็บแสดงข้อความ **“กำลังแสดงข้อมูลสำรอง ข้อมูลอาจไม่ใช่ข้อมูลล่าสุด”** ผลนี้จึงอ้างถึงข้อมูลที่ผู้ใช้เห็นจาก fallback ในรอบตรวจ ไม่ยืนยันข้อมูลล่าสุดใน DynamoDB
- เทียบรายการที่แสดงจริงกับ `public/data/partner-data-backup.json` และ `data/partners.json` ใน branch `Sources`; รายชื่อและ ID ตรงกับรายการที่ตรวจบนหน้าจอ
- ใช้ [Sources เว็บไซต์ทางการ](official-web-source-inventory.md) และ [Sources LinkedIn](linkedin-source-inventory.md) พร้อมตรวจแหล่งสหกิจที่เว็บสาขาลิงก์ถึงเพิ่มเติม
- “ยังไม่พบ source” หมายถึงยังไม่มีหลักฐานยืนยันในแหล่งที่ตรวจ ไม่ใช่ข้อสรุปว่าข้อมูลนั้นไม่มีจริง

## ลำดับที่เสนอให้ทีมทำ

1. แก้การผูกกิจกรรม AIST กับ King Power Click และลิงก์ placeholder ของสหกิจ
2. ยืนยันวันที่ KBTG, Spark Camp, Kansai, Ascend และกิจกรรมสหกิจก่อนแสดงเป็นวันที่แน่นอน
3. ยืนยันข่าว MoU Ascend และรายชื่อผู้ประสานงาน; ระบุข้อมูลตัวอย่างให้ชัดถ้าใช้สำหรับ demo
4. เพิ่ม CNC, Yarsi, NVIDIA workshop, รอบ AIST ของปริญญา และข่าว MoU Embedded LLM / AGICAFET; PRAGMA34 ต้องยืนยันวันก่อน
5. ทบทวนรายการ IPB ที่อาจซ้ำ และเพิ่มลิงก์ต้นทางในแต่ละ record เพื่อให้ตรวจย้อนหลังได้

ผลตรวจเป็นรายงานเท่านั้น ยังไม่ได้แก้ข้อมูลเว็บไซต์ API หรือฐานข้อมูล และไม่ได้ยืนยันความครบถ้วนของข่าวทุกหน้าในเว็บไซต์ต้นทาง
