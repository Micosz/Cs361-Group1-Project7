# AI Usage Declaration — CSTUHub

เอกสารนี้สรุปการใช้ AI และงานที่เกี่ยวข้องของสมาชิกตลอดโครงการ CSTUHub โดยอ้างอิงคำชี้แจงการใช้ AI ที่สมาชิกเคยจัดทำ บทสนทนาการทำงาน และประวัติ commit/PR ที่ตรวจได้ถึงวันที่ 3 พฤศจิกายน 2569

**รอสมาชิกตรวจสอบก่อนส่ง:** รายการที่ระบุว่า “รอยืนยันการใช้ AI” เป็นงานที่พบใน GitHub แต่ commit หรือ PR ไม่สามารถยืนยันได้ว่าใช้ AI หรือไม่ รวมถึงผู้เปิด PR หรืออัปโหลดอาจไม่ใช่ผู้สร้างงานทั้งหมด โปรดให้สมาชิกแต่ละคนยืนยันเครื่องมือ ขอบเขตการใช้ และการตรวจสอบที่ตนทำจริง แล้วแก้หรือลบรายการที่ไม่ตรง

## นายชนกานต์ คงรัชตภิญโญ — Micosz

### Type of Work

ใช้ ChatGPT และ Codex ช่วยจัดโครงสร้างและเรียบเรียงเอกสาร โดยนำ Requirements, Issues และ Acceptance Criteria มาเป็นข้อมูลตั้งต้น รวมถึงช่วยเปรียบเทียบทางเลือก Hosting บน AWS และจัดทำข้อมูลประกอบ Architecture Diagram

ใช้ Codex ช่วยวิเคราะห์ปัญหาและดำเนินการพัฒนาส่วนต่าง ๆ ของเว็บและระบบ เช่น หน้าแสดงภาพรวมและกราฟ Stakeholder การจัดการและนำเข้าผลตอบรับจากแบบฟอร์ม การตรวจสอบสิทธิ์และการจัดเก็บไฟล์ ตลอดจนช่วยเตรียมการย้ายระบบไป Singapore และจัดทำเอกสารประกอบ

### Verification and Modifications

ตรวจเทียบเอกสารกับ Requirements และข้อมูล `partners.json` แล้วปรับขอบเขตและเนื้อหาให้ตรงกับโครงการ สำหรับงานพัฒนา มีบันทึกการตรวจโค้ดและทดลองหน้าเว็บในเครื่อง รวมถึงการปรับแก้ตามผลตรวจและข้อคิดเห็น เช่น PR #228 ระบุการตรวจหน้าจอหลายขนาด การกรอง และกรณีข้อมูลว่างด้วยข้อมูลจำลอง

## นายวุฒิกร บุญทวี — wuttikornboontawee

### Type of Work

ใช้ Gemini Pro ช่วยออกแบบ Data Dictionary ปรับโครงสร้างข้อมูลและ Path รูปภาพใน `partners.json` และช่วยดำเนินการปรับ `openModal` ให้แสดงโลโก้ รูปภาพ และรายละเอียดจากข้อมูลแบบ Dynamic

**งานที่เกี่ยวข้อง รอยืนยันการใช้ AI:** GitHub แสดงงานเตรียมข้อมูลและเชื่อมหน้าเว็บกับ API Gateway และ DynamoDB รวมถึงงานจัดการกิจกรรมและโครงการแลกเปลี่ยน เช่น การเชื่อมคู่ความร่วมมือ ผู้รับผิดชอบ และสถานะ นอกจากนี้มีงานปรับหน้าผู้ติดต่อ ประวัติความสัมพันธ์ และภาพรวมให้อ่านง่ายขึ้น

### Verification and Modifications

ตรวจและปรับ JavaScript/HTML รวมถึงการเชื่อมโยงข้อมูล JSON และ Path รูปภาพ เพื่อแก้กรณีแสดงข้อมูลไม่ครบหรือไม่ถูกต้อง ใน PR #218 มีบันทึกผลตรวจชุดทดสอบหน้า UI และ Dashboard

## นายศุภวิชญ์ ไม้จัตุรัส — Supavit-49
