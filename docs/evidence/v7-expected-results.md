## 1. คำถามรายงาน (#265)

> ในเทอมที่เลือก ภายใต้ MoU ฉบับนี้ มีกิจกรรมกี่งาน มีนักศึกษายืนยันสิทธิ์ Exchange กี่คน และมีประเด็น Feedback อะไรให้ติดตาม

หน้า Overview: เลือก "ข้อตกลง MoU / MoA" + ช่วงวันที่ → แผง **สรุปตามข้อตกลง** และปุ่ม **ส่งออกรายงาน CSV** ใช้ตัวกรองชุดเดียวกัน

## 2. นิยามที่ใช้นับ

| ตัวเลข | นับอย่างไร | ที่มาในโค้ด |
| --- | --- | --- |
| กิจกรรมของข้อตกลง | Activity ที่ `agreementIds` มีรหัสข้อตกลงนั้น (ขอบเขตเดียวกัน) และ `periodDate` อยู่ในช่วงที่เลือก | `gateway.py` `overview` → `linked_agreements` |
| Exchange ของข้อตกลง | Exchange ที่ `agreementId` เป็นข้อตกลงนั้น (ขอบเขตเดียวกัน) และช่วง `startDate`–`endDate` ซ้อนกับช่วงที่เลือก | เดียวกัน |
| **นักศึกษายืนยันสิทธิ์** | ใบสมัครในรอบรับสมัครของ Exchange ข้างบน ที่ประกาศผล `passed` แล้ว และ **มี `confirmedAt`** (หรือรอบนั้นไม่ต้องยืนยัน) นับรหัสนักศึกษาไม่ซ้ำ | `backend/overview_admissions.py` (#286 `exchangeRound` / `exchangeApplication`) |
| ผ่านแต่ยังไม่ยืนยัน | ประกาศผล `passed` แต่ยังไม่มี `confirmedAt` — **แสดงแยก ไม่นับรวม** | เดียวกัน (`awaitingConfirmation`) |
| ไม่นับ | ถูกปฏิเสธ (`declined`) หรือยังไม่ประกาศผล | เดียวกัน |
| Feedback ของข้อตกลง | `feedback` (ความคิดเห็น) และ `formFeedback` (ชุด/คำตอบ) ที่ parent เป็นกิจกรรมหรือ Exchange ของข้อตกลงนั้น | `gateway.py` (#264) |
| Feedback ไม่ระบุข้อตกลง | ผูกกับคู่ความร่วมมืออย่างเดียว — แสดง "ยังไม่ระบุข้อตกลง" และ **ไม่บวกเข้าฉบับใด** | เดียวกัน |

ตัดสินแล้ว: "ยืนยันสิทธิ์" = `confirmedAt` (นักศึกษากดยืนยัน) ไม่ต้องรอคู่สัญญาตอบรับ (`enrolledAt`)
รายงานส่งเฉพาะจำนวน ไม่ส่งชื่อหรือรหัสนักศึกษา; Overview เปิดได้เฉพาะ Staff/Executive
