## 1. คำถามรายงาน (#265)

> ในเทอมที่เลือก ภายใต้ MoU ฉบับนี้ มีกิจกรรมกี่งาน มีนักศึกษายืนยันสิทธิ์ Exchange กี่คน และมีประเด็น Feedback อะไรให้ติดตาม

## 2. นิยามที่ใช้นับ

| ตัวเลข | นับอย่างไร | ที่มาในโค้ด |
| --- | --- | --- |
| กิจกรรมของ MoU | Activity ที่ `agreementIds` มีรหัส MoU นั้น และ `periodDate` อยู่ในช่วงที่เลือก | `activity.agreementIds`, `periodDate` |
| นักศึกษายืนยันสิทธิ์ | ใบสมัครที่ผ่าน ยืนยันสิทธิ์แล้ว และถูกเพิ่มเข้า Exchange (`enrolledAt`) ของ Exchange ที่ `agreementId` เป็น MoU นั้น นับรหัสนักศึกษาไม่ซ้ำ | `admissions.py` (#286), `exchange.participantUserIds` |
| ผู้สมัครที่ยังไม่ยืนยัน | ใบสมัครที่ยังไม่มี `confirmedAt` หรือยังไม่ `enrolledAt` — **ต้องไม่ถูกนับ** | `exchangeApplication` |
| Feedback ของ MoU | `feedback` / `formFeedback` ที่ parent เป็น Activity หรือ Exchange ของ MoU นั้น | `parentType`, `parentId` |
| Feedback ไม่ระบุข้อตกลง | ผูกกับ Partner อย่างเดียว — แสดงเป็น "ยังไม่ระบุข้อตกลง" และ**ไม่เพิ่มยอดรายฉบับ** | `parentType = partner` |

ข้อที่ต้องตกลงกับทีม: "ยืนยันสิทธิ์" หมายถึงนักศึกษากดยืนยันแล้ว (`confirmedAt`) หรือเข้าร่วมครบขั้นแล้ว (`enrolledAt` ซึ่งรวมการตอบรับของคู่สัญญา) ร่างนี้ใช้ **`enrolledAt`**
