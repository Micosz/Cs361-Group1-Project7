# CS361 Group 1 - Project 7

## Project Overview
โครงการนี้มีเป้าหมายสร้างระบบกลางสำหรับบริหารข้อมูลคู่ความร่วมมือและผู้มีส่วนได้ส่วนเสียของหลักสูตร เนื่องจากปัจจุบันข้อมูลคู่ความร่วมมือ เอกสาร ข้อตกลง กิจกรรม และผู้ประสานงานมักกระจายอยู่ในหลายไฟล์หรือหลายระบบ ทำให้ติดตามสถานะ ระยะเวลาของข้อตกลง ประวัติการดำเนินงาน และผลลัพธ์ที่เกิดขึ้นได้ยาก ระบบจึงรวบรวมข้อมูลที่กำหนดให้เผยแพร่ไว้ในหน้าเว็บเดียว เพื่อให้ผู้ใช้ทั่วไปและนักศึกษาสามารถเข้าถึงข้อมูลได้โดยไม่ต้องเข้าสู่ระบบหรือค้นหาจากหลายแหล่ง

## Version 1 Scope
V1 ให้บริการข้อมูลคู่ความร่วมมือ ความร่วมมือ และกิจกรรมบางส่วนที่กำหนดให้เผยแพร่ โดยมีหน้าสำหรับแสดงข้อมูลและรายละเอียดที่ผู้ใช้เลือกดู
